# Project Instructions for ChatGPT

This project follows **Spec-Driven Development (SDD)**. Before proposing a
plan or changing code, read:

| File | Purpose |
| --- | --- |
| `project.config.md` | Project identity, stack, and configuration |
| `docs/MASTER_PROMPT.md` | Mandatory workflow, rules, and boundaries |
| `docs/SPECIFICATIONS.md` | Current project requirements |
| `docs/ARCHITECTURE.md` | Stack and technical decisions |
| `docs/DESIGN.md` | Visual design system, if it exists |
| `memory.md` | Context, decisions, and lessons learned |
| `task.md` | Current state, backlog, and context snapshot |

**Follow `docs/MASTER_PROMPT.md` strictly.** If it conflicts with project
specifications, stop and report the contradiction before proceeding.

ChatGPT does not automatically load this file or register prompts from
`.chatgpt/commands/`. When using ChatGPT, provide this file and the relevant
project files in the conversation, or paste the desired phase prompt from
`.chatgpt/commands/`.
